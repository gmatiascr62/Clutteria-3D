# Atribuciones

- **Motor:** [Godot Engine](https://godotengine.org) 4.3, licencia MIT.
- **Modelos 3D:** todos originales de este proyecto, generados por código a
  partir de primitivas (`src/game/mesh_kit.gd`).
- **Texturas / materiales:** shaders procedurales originales
  (`src/game/shaders/`). No se usan imágenes externas.
- **Sonidos:** sintetizados por código al iniciar (`src/autoload/sfx.gd`).
- **Íconos de interfaz:** dibujados con polígonos (`src/ui/vector_icon.gd`);
  `icon.svg` es original.
- **Fuente:** la fuente por defecto incluida en Godot.

No se incluyen recursos de terceros ni con licencias restrictivas.
